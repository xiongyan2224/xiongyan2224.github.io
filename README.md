# Yan Xiong — Academic Website

A lightweight academic website built from `Academic_CV.pdf` and ready for GitHub Pages.

## Publish with GitHub Pages

1. Create a public repository named `xiongyan2224.github.io`.
2. Upload the contents of this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
5. The site will appear at `https://xiongyan2224.github.io/`.

No build step or dependencies are required.
